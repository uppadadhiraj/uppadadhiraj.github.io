Every programmer's first program prints *hello, world*. So does this blog.

I'm a final-year BTech student, and I build a lot of things that never get written down. The decisions, the dead ends, the 2 a.m. bug that turned out to be a missing semicolon: all of it disappears once the project works. This blog is where I stop letting that happen.

## What to expect

- **Build logs** for my projects: what I built, how, and what I'd change
- **Bug postmortems**: the nasty ones, and how I found them
- **Learning notes**: right now that means moving from Python to Java

## A small taste

Since I'm switching languages, here's the same program in both:

```python
print("hello, world")
```

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("hello, world");
    }
}
```

One line versus five. More on that in a later post.
